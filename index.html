Marklet

A portable Markdown editor that works entirely offline, in a single HTML file. Put it on a network drive, a USB stick or your desktop and open it in any modern browser.

Keyboard shortcuts

On macOS, use Cmd instead of Ctrl.

Save · Save as · Open Ctrl+S · Ctrl+Shift+S · Ctrl+O
Bold · Italic · Strikethrough Ctrl+B · Ctrl+I · Ctrl+Shift+X
Code · Link Ctrl+E · Ctrl+K
Heading 1–6 · Normal text Ctrl+Alt+1…6 · Ctrl+Alt+0
Bulleted · Numbered list · Quote Ctrl+Shift+8 · Ctrl+Shift+7 · Ctrl+Shift+.
Find and replace Ctrl+F
Undo · Redo Ctrl+Z · Ctrl+Y
Indent · Outdent Tab · Shift+Tab (press Esc then Tab to leave the editor)
Fold a section Ctrl+Shift+[ · Ctrl+Shift+]

Privacy and IT

  • No installation, no server, no account, no telemetry. The page has a Content Security Policy that blocks all network access, so remote images appear as placeholders.
  • Autosave uses this browser's local storage, on this computer only.
  • Saving back to the opened file uses the browser's File System Access API (Chrome, Edge). If the API is unavailable or blocked by policy, Save downloads a copy instead.
